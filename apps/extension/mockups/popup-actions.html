Machdown popup — destination-first

Three layouts that address the same four notes. Every save button is live: click it and it plays the in-button animation (spin → check → “Saved”) with no toast. Buttons return to idle after 1.4s so you can click again.

  1. No toast. The button itself reports the outcome, so nothing covers the page.
  2. Search and Settings are icons at the top right in every variant.
  3. Knowledge base vs Downloads folder are two visibly separate destinations, never one button with a hidden mode.
  4. “Save N tabs” leaves the main toolbar. Bulk save still has two one-click destinations (KB or local folder) wherever it lives.

A · Two destinations, tabs in the footer

Knowledge base and Downloads sit side by side as equal-width buttons, KB filled so it reads first. Copy and Bookmark drop to a quieter row. Open tabs get their own footer strip with two direct destinations, so bulk saving is one click without crowding the page actions.
